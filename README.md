# Pirate Games Plus

Android-каталог бесплатных игр и проектов с открытым исходным кодом. Приложение показывает краткое описание, платформы и ведёт на официальные страницы разработчиков.

## Сборка APK

GitHub Actions запускает сборку автоматически после push в ветку `main` или вручную через **Actions → Build Android APK → Run workflow**.

Готовый файл находится в артефакте **PirateGamesPlus-debug-apk** в завершённом запуске workflow.

## Состав

- Android-приложение на Java без сторонних библиотек.
- Поиск по каталогу.
- Ссылки на официальные страницы проектов.
- Чёрно-красный интерфейс.

Каталог не распространяет пиратские копии и не обещает проверку файлов на вирусы. Перед установкой проверяйте источник и условия распространения игры.
